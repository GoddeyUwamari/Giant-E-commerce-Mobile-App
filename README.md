# Giant E-commerce Mobile App 🛍️

A cross-platform e-commerce mobile application with shopping cart, product catalog, and user authentication built with React Native and Expo.

![React Native](https://img.shields.io/badge/React_Native-20232A?style=flat-square&logo=react)
![Expo](https://img.shields.io/badge/Expo-000020?style=flat-square&logo=expo)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript)

## ✨ Features

- 🛒 Shopping cart functionality
- 📱 Cross-platform (iOS & Android)
- 🔍 Product browsing and search
- 👤 User authentication
- 💳 Checkout process
- 📦 Order management

## 🛠️ Tech Stack

- **React Native** - Mobile framework
- **Expo** - Development platform
- **JavaScript** - Programming language
- **React Navigation** - Navigation library

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- Expo CLI
- iOS Simulator or Android Emulator

### Installation
```bash
# Clone the repository
git clone https://github.com/GoddeyUwamari/Giant-E-commerce-Mobile-App.git

# Navigate to project
cd Giant-E-commerce-Mobile-App

# Install dependencies
npm install

# Start the app
npx expo start
```

## 📱 Running the App
```bash
# Start development server
npx expo start

# Run on iOS
npx expo start --ios

# Run on Android
npx expo start --android
```
